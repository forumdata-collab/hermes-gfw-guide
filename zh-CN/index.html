0 架构

0双通道架构

唔好将所有鸡蛋放同一个篮。呢个方案用两条独立通道互相后备：VM 慨 VLESS/REALITY 系主力，CF Worker 慨 edgetunnel 系后备 — 一条出事另一条即刻顶上。

📱 手机→ 自动切换→ 🟢 VM REALITY（主力）→ 🌐 互联网
📱 手机→ 自动切换→ 🟠 CF edgetunnel（后备）→ 🌐 互联网
VM REALITY（主力）CF edgetunnel（后备）
协议VLESS + REALITY（TLS 伪装真实网站）VLESS + WebSocket + TLS（CF CDN 隧道）
伺服器Oracle ARM VM（大阪）Cloudflare Worker（边缘节点全球）
费用永久免费（OCI Always Free）永久免费（CF Workers Free Tier）
过墙能力⭐⭐⭐⭐⭐ 最稳（伪装iTunes，无SNI标记）⭐⭐⭐⭐ 强（自订 domain，睇落系普通CF网站）
速度稳定但延迟略高Ping低（CF Anycast），但WS有overhead
风险VM IP可能被封（Oracle段）CF整段被干扰机率较低，但免费tier有限额
核心理念：两条通道走完全唔同慨基建（Oracle vs Cloudflare），唔会同时出事。 VM IP 被封 → 手机自动跳 CF 后备 → 继续上网。呢个就系「双通道」慨意义。

2 VM sing-box

2VM 部署 sing-box（VLESS/REALITY 主力）

呢部分喺 Oracle VM 上面安装 sing-box，建立 VLESS + REALITY 入站 — 世界最先进慨反侦测协议，伪装成正常 HTTPS 网站（iTunes.apple.com），GFW 无法分辨。

安装 sing-box

curl -fsSL https://get.sing-box.dev | bash

或者用包管理：Ubuntu 22.04+snap install sing-box。

生成凭证唯一需要记低慨嘢

sing-box generate uuid sing-box generate reality-keypair sing-box generate rand 4 --hex

输出三个关键值，全部要记低：

  • UUID：用户身分（例如xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx）
  • PrivateKey：伺服器私钥（配对公钥用，例如xxxxxxxxxxxxxxxxxxxxxxx）
  • PublicKey：公钥（手机 App 用，例如xxxxxxxxxxxxxxxxxxxxxxx）
  • ShortID：短码（例如ab12，4-8个hex字元）

写 sing-box server config

sudo nano /etc/sing-box/config.json
{ "inbounds": [ { "type": "vless", "tag": "vless-reality", "listen": "0.0.0.0", "listen_port": 443, "users": [ { "uuid": "<你的UUID>", "flow": "xtls-rprx-vision" } ], "tls": { "enabled": true, "server_name": "itunes.apple.com", "reality": { "enabled": true, "handshake": { "server": "itunes.apple.com", "server_port": 443 }, "private_key": "<你的PrivateKey>", "short_id": ["<你的ShortID>"] } } } ], "route": { "rules": [{ "outbound": "any", "action": "hijack-dns" }], "final": "direct", "auto_detect_interface": true } }

改四个 placeholder：<你的UUID>、<你的PrivateKey>、<你的ShortID>。其他照抄。

验证 + 启动

sudo sing-box check -c /etc/sing-box/config.json sudo systemctl enable sing-box sudo systemctl start sing-box sudo systemctl status sing-box

显示active (running)即成功。

⚠️ 实测踩坑：
•Oracle NSG ≠ iptables：VM 入面开咗 UFW 唔代表通，OCI Console 慨 Security List 都要开（两层防火墙）
•443 port 可能被占用：装 sing-box 前先ss -tlnp | grep 443，俾其他服务占咗就移走先
•Bot 409 Conflict：sing-box 服务同旧 polling 进程撞 →pkill -f sing-box先启动新服务
3 CF edgetunnel

3CF 部署 edgetunnel（Worker 后备通道）

edgetunnel 系基于 Cloudflare Worker 慨 VLESS 代理，行 WebSocket 隧道。 VM IP 被封时，手机会自动跳去呢条后备。全部跑喺 CF 免费 tier，唔需要伺服器。

下载 edgetunnel Worker 代码

curl -sL "https://raw.githubusercontent.com/cmliu/edgetunnel/main/_worker.js" -o _worker.js

CM liu 慨 edgetunnel 2.x — 支援 VLESS/Trojan + 管理后台 + 订阅生成。

生成 UUID（同 VM 唔同，各自独立）

python3 -c "import uuid; print(uuid.uuid4())"

记低，格式xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx。

部署到 Cloudflare（wrangler CLI 或 Dashboard）

最稳阵：Dashboard 手动

  • CF Console → Workers & Pages → Create Worker → 命名edgetunnel
  • 贴上_worker.js内容 → Deploy
  • Settings → Variables → 加 secret：ADMIN（管理密码）+UUID（你慨 UUID）
  • Settings → Bindings → 加 KV namespace（名称KV）
  • Trigger → Add Custom Domain → 填vpn.你的域名.com
⚠️ 关键：一定要绑自订 domain（唔系 *.workers.dev）— *.workers.dev 喺大陆多数被墙！自订 domain 睇落系你慨正常网站，GFW 唔会封。

验证后台

浏览器开https://vpn.你的域名.com/admin→ 输入 ADMIN 密码登入管理后台。

攞订阅连结

订阅 URL 格式：
https://vpn.你的域名.com/sub?token=<計算得出嘅token>

或者直接用 vless:// 连结（见 §4 手机配置）。

4 手机配置

4手机客户端配置

sing-box / v2rayNG / Shadowrocket 等 App 都支援 vless:// 连结直接汇入。

汇入三条 vless:// 连结

① 主力：vless://@:443?encryption=none&security=reality&sni=itunes.apple.com&fp=chrome&pbk=&sid=&flow=xtls-rprx-vision&type=tcp&headerType=none#VM-主力-Reality ② 后备：vless://@vpn.你的域名.com:443?security=tls&type=ws&host=vpn.你的域名.com&fp=chrome&sni=vpn.你的域名.com&path=%2F&encryption=none#CF-后备-Edgetunnel ③ （可选）VM 8443 端口第二通道（跟上述格式改port）

用真实值替换<UUID>、<VM_IP>、<PublicKey>、<CF_UUID>等。

设定自动切换（自动选择最快节点）

  • v2rayNG：长按节点 → 勾选多个 → 顶按右上角 ⟳ 测速 → 拣「自动选择」
  • sing-box GUI：选多个 outbound → urltest 自动拣
  • Shadowrocket / Stash：选「自动选择」模式
自动切换效果：正常时用 VM REALITY（最快最稳）；VM IP 被封时 → 自动跳 CF edgetunnel → 上网无中断。恢复后自动跳返主力。

7 踩坑合集

7踩坑合集（全部亲测）

Q：所有网页报 ERR_QUIC_PROTOCOL_ERROR？

原因：edgetunnel 系 WebSocket（TCP only），唔支援 QUIC（UDP）。 Chrome 预设优先试 QUIC，撞墙就报错。
解决：手机 App 设定加入路由规则block QUIC，或者喺 Chrome 设定chrome://flags/#enable-quic→ Disabled。 REALITY 通道冇呢个问题。

Q：Oracle VM 侦测到 NSG 阻挡？

原因：Oracle 有两层防火墙 — VM 入面 UFW + OCI Console Security List，两层都要开。
解决：OCI Console → Networking → Security Lists → Add Ingress Rules → 开 22/443/8443。

Q：sing-box 409 Conflict？

原因：两个 sing-box 进程撞同一个 inbound port。
解决：pkill -f sing-box停晒所有旧进程，再systemctl start sing-box。

Q：edgetunnel 自订 domain 显示 CF 错误页？

原因：Cert 仲喺 provisioning 或者 Worker 路由冲突。
解决：等 1-3 分钟 cert 自动生效；如果仲系，确认 Worker Route 冇同其他 record 抢。

Q：Oracle 回收实例？

免费 VM 长期冇活动会被回收。 sing-box 24/7 运行本身维持活动。加 keepalive：
crontab -e→*/30 * * * * echo "alive $(date)" >> ~/keepalive.log

8 安全

🔒安全注意事项

✅ 应该做❌ 唔好做
UUID 随机生成（唔好用网上范本）唔好同人共用 UUID / 私钥
API Token 只赋予最小权限（Workers only）唔好将 Token / Key 提交去 GitHub
VM SSH 用金钥认证（唔用密码）唔好开放 Root SSH 登入
定期更新 sing-box（有安全修复）唔好用过时慨 sing-box 版本
edgetunnel 后台设 ADMIN 密码唔好留空 ADMIN（任何人都可以管理）
