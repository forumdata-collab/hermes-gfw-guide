0 architecture

0Dual channel architecture

It's not easy to put all your eggs in the same basket. This solution uses two independent channels to back up each other: the VLESS/REALITY of the VM is the main channel, and the edgetunnel of the CF Worker is the backup - if one fails, the other one will immediately take over.

📱 mobile phone→ Automatic switching→ 🟢 VM REALITY (main force)→ 🌐Internet
📱 mobile phone→ Automatic switching→ 🟠 CF edgetunnel (backup)→ 🌐Internet
VM REALITY (main force)CF edgetunnel (fallback)
agreementVLESS + REALITY (TLS disguises real website)VLESS + WebSocket + TLS (CF CDN tunnel)
serverOracle ARM VM (Osaka)Cloudflare Worker (edge node global)
costOCI Always FreeFree forever (CF Workers Free Tier)
Wall-passing ability⭐⭐⭐⭐⭐ The most stable (disguised as iTunes, no SNI tag)⭐⭐⭐⭐ Strong (custom domain, look at the ordinary CF website)
speedStable but slightly higher latencyPing is low (CF Anycast), but WS has overhead
riskVM IP may be blocked (Oracle segment)The probability of interference in the entire CF section is low, but the free tier has a limit.
Core philosophy:The two channels use completely different infrastructure (Oracle vs Cloudflare), so nothing will happen at the same time. The VM IP is blocked → the phone automatically jumps to CF backup → continue to surf the Internet. This is the meaning of "dual channel".

2VM sing-box

2VM deployment sing-box (VLESS/REALITY main force)

This part installs sing-box on Oracle VM and creates VLESS + REALITY inbound - the world's most advanced anti-detection protocol, disguised as a normal HTTPS website (iTunes.apple.com), which GFW cannot distinguish.

Install sing-box

curl -fsSL https://get.sing-box.dev | bash

Or use package management: Ubuntu 22.04+snap install sing-box.

Generate credentialsThe only thing to remember

sing-box generate uuid sing-box generate reality-keypair sing-box generate rand 4 --hex

Output three key values, all of which must be recorded:

  • UUID:User identity (e.g.xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)
  • PrivateKey: Server private key (used to pair with public key, for examplexxxxxxxxxxxxxxxxxxxxxxx)
  • PublicKey: Public key (for mobile app, for examplexxxxxxxxxxxxxxxxxxxxxxx)
  • ShortID:short code (e.g.ab12, 4-8 hex characters)

Write sing-box server config

sudo nano /etc/sing-box/config.json
{ "inbounds": [ { "type": "vless", "tag": "vless-reality", "listen": "0.0.0.0", "listen_port": 443, "users": [ { "uuid": "<yourUUID>", "flow": "xtls-rprx-vision" } ], "tls": { "enabled": true, "server_name": "itunes.apple.com", "reality": { "enabled": true, "handshake": { "server": "itunes.apple.com", "server_port": 443 }, "private_key": "<yourPrivateKey>", "short_id": ["<yourShortID>"] } } } ], "route": { "rules": [{ "outbound": "any", "action": "hijack-dns" }], "final": "direct", "auto_detect_interface": true } }

Change four placeholders:<你的UUID>,<你的PrivateKey>,<你的ShortID>. Others copy.

Verify + Start

sudo sing-box check -c /etc/sing-box/config.json sudo systemctl enable sing-box sudo systemctl start sing-box sudo systemctl status sing-box

showactive (running)That is success.

⚠️ Actual test pitfalls:
•Oracle NSG ≠ iptables: Just because UFW is turned on in the VM does not mean that it is passable. The Security List of the OCI Console must be turned on (two-layer firewall).
•Port 443 may be occupied: Before installing sing-boxss -tlnp | grep 443, then move them first to let other services occupy them.
•Bot 409 Conflict: sing-box service collides with old polling process →pkill -f sing-boxStart the new service first
3CF edgetunnel

3CF deploys edgetunnel (Worker backup channel)

edgetunnel is a VLESS proxy based on Cloudflare Worker that performs WebSocket tunneling. When the VM IP is blocked, the phone will automatically jump to this backup. All run in CF free tier, no server required.

Download edgetunnel Worker code

curl -sL "https://raw.githubusercontent.com/cmliu/edgetunnel/main/_worker.js" -o _worker.js

CM liu's edgetunnel 2.x — supports VLESS/Trojan + management background + subscription generation.

Generate UUID (different from VM, independent of each other)

python3 -c "import uuid; print(uuid.uuid4())"

7 Trampling Collection

7A collection of pitfalls (all personally tested)

Q: All web pages report ERR_QUIC_PROTOCOL_ERROR?

Reason:edgetunnel is WebSocket (TCP only) and does not support QUIC (UDP). By default, Chrome tries QUIC first and reports an error when it hits a wall.
Solution:Mobile App settings to add routing rulesblock QUIC, or in Chrome Settingschrome://flags/#enable-quic→ Disabled. The REALITY channel does not have this problem.

Q: Oracle VM detects NSG blocking?

Reason:Oracle has two layers of firewall - VM entry UFW + OCI Console Security List, both layers must be enabled.
Solution:OCI Console → Networking → Security Lists → Add Ingress Rules → Open 22/443/8443.

Q: sing-box 409 Conflict?

Reason:Two sing-box processes hit the same inbound port.
Solution:pkill -f sing-boxStop all old processes and thensystemctl start sing-box.

Q: Edgetunnel custom domain displays CF error page?

Reason:Cert is involved in provisioning or Worker routing conflicts.
Solution:Wait 1-3 minutes for the cert to take effect automatically; if so, confirm that the Worker Route is not competing with other records.

Q: Oracle recycles instances?

Free VMs that have no activity for a long time will be recycled. sing-box runs itself 24/7 to maintain activity. Add keepalive:
crontab -e→*/30 * * * * echo "alive $(date)" >> ~/keepalive.log
